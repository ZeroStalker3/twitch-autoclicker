# 🎁 Twitch Auto Bonus Clicker

Автоматический сбор бонусных баллов на Twitch с графическим интерфейсом.

## ✨ Возможности
- Автоматический клик по кнопке получения бонуса
- Имитация человеческого поведения (скролл, движение мыши, паузы)
- GUI с логами, статистикой и балансом в реальном времени
- Перетаскиваемое окно, сворачивание, скрытие
- Горячая клавиша Ctrl+X для полного удаления

## 📦 Установка
1. Установите [Tampermonkey](https://www.tampermonkey.net/) или [Violentmonkey](https://violentmonkey.github.io/)
2. Нажмите [Install](ссылка_на_greasyfork)
3. Откройте любую страницу Twitch — появится панель управления

## ⌨️ Управление
| Действие | Способ |
|----------|--------|
| Старт/Стоп | Кнопка START/STOP в GUI |
| Скрыть панель | Кнопка HIDE |
| Свернуть | Кнопка − |
| Показать скрытую панель | Ctrl + двойной клик |
| Полное удаление | Ctrl + X |

## 🐛 Баги и предложения
Создавайте [Issues](https://github.com/ZeroStalker3/twitch-autoclicker/issues) с указанием браузера, менеджера скриптов и версии.
- Браузер и версия
- Менеджер скриптов (Tampermonkey/Violentmonkey)
- Версия скрипта (видна в заголовке GUI)
- Скриншот ошибки из консоли (F12)
